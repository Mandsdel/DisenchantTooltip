# Disenchant Tooltip

A World of Warcraft: Forever addon that will display verified disenchant outcomes in item tooltips.

## Status

Initial repository setup. The implementation is paused while the ForeverDB data-source integration is configured.

## Data source

The planned updater will use ForeverDB only through a user-owned API key stored locally with Windows DPAPI. No API keys or generated local credentials are committed to this repository.

Every tooltip section that displays ForeverDB-derived data will visibly credit the source as `Data from ForeverDB.net`. This repository and future project documentation also include the required visible link:

<a href="https://foreverdb.net">Data from ForeverDB.net</a>
